게임 설명은 첨부 개발 지시서가 인용한 GDD v1.2 요약을 기준으로 작성했습니다. 원본 GDD와 Unity 구현을 직접 대조한 것은 아닙니다. 실제 게임 화면이나 기능 완료를 암시하지 않도록 기획 목표 및 콘셉트 그래픽임을 표시했습니다.

기존 작업 폴더의 `#` 문자 때문에 Vite가 콘텐츠 경로를 해석하지 못해, 동일 소스를 `#` 없는 검증용 복사본에서 실행했습니다. 검증 로그와 화면 캡처는 로컬 `.qa/`에 보관하고 공개 Git 저장소에는 포함하지 않습니다.

배포 완료 판정은 저장소 Pages Source를 GitHub Actions로 설정하고, 사용자 검토·병합 이후 Actions deploy 성공 및 운영 URL 확인까지 필요합니다. PR 생성 자체를 배포 성공으로 간주하지 않습니다.
